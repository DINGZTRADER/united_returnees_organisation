# Vercel production deployment

The production URO application is deployed from the `main` branch of `DINGZTRADER/united_returnees_organisation` to the Vercel project `uro-modern-prototype`.

Production URL: https://uro-modern-prototype.vercel.app

The application uses the Supabase project `uro-secure-intake` for authentication, membership data, support cases, opportunities, payments and receipts.
